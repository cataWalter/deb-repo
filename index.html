Pinger APT Repository

To install Pinger on Debian or Ubuntu:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://cataWalter.github.io/deb-repo/public.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/pinger.gpg
echo "deb [signed-by=/etc/apt/keyrings/pinger.gpg] https://cataWalter.github.io/deb-repo stable main" | sudo tee /etc/apt/sources.list.d/pinger.list
sudo apt update
sudo apt install pinger
